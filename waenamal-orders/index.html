주문 수정

설정

1 구글 시트 연결

연결하면 가게 PC·집 PC·아이폰에서 같은 장부를 봅니다. 연결 전에는 이 브라우저에만 저장됩니다.

2 1분 연결 순서

  1. 구글 시트 왜나말_주문장부를 엽니다.
  2. 위쪽 메뉴 확장 프로그램 → Apps Script 클릭.
  3. 열린 편집기의 내용을 모두 지우고, 아래 코드를 붙여넣기 → 💾 저장.
  4. 오른쪽 위 배포 → 새 배포 → 유형 웹 앱 선택.
  5. 실행 계정: 나 / 액세스 권한: 모든 사용자 → 배포 → 권한 승인.
  6. 나오는 웹 앱 URL을 복사해 위 1번 칸에 붙여넣고 연결 테스트.

※ 코드를 고치면 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영됩니다.
