# 왜나말 주문장부

카톡 1:1 대화를 통째로 붙여넣으면 주문서로 정리해 주는 사장님 전용 미니 웹앱입니다.
GitHub Pages로 열리며, 아이폰 홈화면에 추가하면 앱처럼 쓸 수 있습니다.

## 되는 일

- **카톡 붙여넣기 자동 정리** — `Ctrl+A → Ctrl+C` 한 대화 1건 또는 여러 건을 한 번에 붙여넣으면
  닉네임·성함·연락처·주소(픽업 일시)·수량·금액·입금 여부·요청사항을 뽑아 미리보기 카드로 보여 줍니다.
  빠진 항목(주소 없음, 미입금 등)은 노란/빨간 배지로 표시되고, 그 자리에서 고쳐 저장할 수 있습니다.
- **주문 장부** — 총 주문·택배 박스·픽업 박스·입금완료 금액·확인필요 건수 요약,
  전체/택배/매장픽업/확인필요 탭, 검색, 입금상태 한 번에 바꾸기, 수정·삭제.
- **내보내기** — CSV(엑셀에서 바로 열림)와 .xlsx 다운로드.
- **구글 시트 연동** — 설정에서 Apps Script 웹 앱 URL을 넣으면 구글 시트와 실시간으로 조회·추가·수정·삭제합니다.
  연결하지 않아도 이 브라우저 저장소에 바로 기록됩니다.

## 처음 세팅 (1분)

1. 구글 시트 `왜나말_주문장부`를 엽니다.
2. `확장 프로그램 → Apps Script`를 열고, 편집기 내용을 모두 지운 뒤
   앱 설정 화면의 **Apps Script 코드**(또는 이 저장소와 함께 받은 `왜나말_AppsScript_코드.txt`)를 붙여넣고 저장합니다.
3. `배포 → 새 배포 → 웹 앱`, 실행 계정 **나**, 액세스 권한 **모든 사용자**로 배포합니다.
4. 나온 웹 앱 URL을 앱의 `설정 → 구글 시트 연결`에 붙여넣고 **연결 테스트**를 누릅니다.
5. 다른 기기(집 PC·아이폰)에서는 설정에 나오는 **다른 기기용 링크**(`?api=`)를 열면 바로 연결됩니다.

## 아이폰 홈화면 추가

Safari로 이 페이지를 연 뒤 `공유 → 홈 화면에 추가`. 아이콘을 누르면 주소창 없이 앱처럼 열립니다.

## 개인정보

- 이 저장소에는 **앱 코드만** 있습니다. 고객 이름·연락처·주소·주문 데이터는 저장소에 없습니다.
- 입력한 주문은 ① 이 브라우저의 저장소(localStorage)와 ② 사장님이 연결한 구글 시트에만 저장됩니다.
- 시트 연동은 사장님 구글 계정의 Apps Script 웹 앱을 통해서만 이뤄지고, 앱은 별도 서버를 쓰지 않습니다.
- 공용 PC에서 쓰셨다면 `설정 → 이 기기 기록 비우기`로 브라우저 저장 기록을 지울 수 있습니다.
